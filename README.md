# 食谱管理器 - Recipe Manager

一个简单易用的Qt食谱管理桌面应用程序，帮助您记录、查看和随机选择食谱。

## 功能特点

- **添加食谱**：通过文本输入框添加新的食谱内容
- **查看食谱**：按添加顺序显示所有已保存的食谱
- **随机食谱**：从已有食谱中随机选择一条显示

## 系统要求

- Windows 7 / 8 / 10 / 11
- 无需安装Qt运行环境（已打包版本）

## 安装与运行

1. 下载并解压 `RecipeManager.zip`
2. 进入 `release` 文件夹
3. 双击 `RecipeManager.exe` 启动程序

## 使用说明

### 1. 添加食谱

- 点击主界面的 **添加食谱** 按钮
- 在弹出的窗口中输入食谱内容
- 点击 **OK** 保存
- 如果不小心点了Cancel，不会保存任何内容
- 如果输入内容为空，会弹出警告提示

### 2. 查看食谱

- 点击 **查看食谱** 按钮
- 如果没有添加过食谱，会弹出提示
- 所有已保存的食谱会按添加顺序显示
- 每条食谱前面带有编号（1、2、3...）
- 每条食谱之间有空白行分隔，方便阅读

### 3. 随机食谱

- 点击 **随机食谱** 按钮
- 如果没有添加过食谱，会弹出提示
- 系统会从所有已保存的食谱中随机选择一条显示
- 每次点击都会重新随机选择

### 4. 界面说明

- 主界面顶部显示问候语"今天想吃点什么？"
- 三个功能按钮水平排列在底部
- 所有对话框都可以拖动窗口边缘调整大小
